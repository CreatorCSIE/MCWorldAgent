## 9. 存储格式
- **level.dat + 散件 chunk .dat**（无 region；"region" 字符串 0 命中）。
- `World.b(File,String)` 静态读 level.dat→NBT（GuiSelect 用）；`World.a(File,String)` 静态删世界；**存盘入口 `World.f()V`**（public final）→ private `b(true)`：FileOutputStream+GZIP 写 level.dat（NBT 根含 RandomSeed/SpawnX/Y/Z/Time + 玩家 NBT）。
- chunk 存储包 `net.minecraft.a.a.e`：`a`=handler 接口、`b`=读（`c(II)→e.e`，文件名 ".dat"，根 tag "Level"）、`d`=写（`a(e.e)V`，FileOutputStream）、`e`=Chunk、`c`=?。World 构造器 `g(File,String[,long])` 内建 handler 并首存。
- 触发链：切世界/退出时 Minecraft.d.a(g,String)V→World.f()V；无周期性 level.dat 重写证据（chunk 保存走 e.d）。
