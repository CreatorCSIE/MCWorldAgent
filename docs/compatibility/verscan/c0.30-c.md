## 8. 存储格式（面 9）

**无 NBT**（全 jar "nbt/NBT" 0 命中）。Classic = **单文件 `level.dat`，GZIP + Java 对象序列化，无 chunk 散件**（jar 内无 region/mcr/anvil 线索；Level 直接持全局 `byte[] blocks`）。

存/取代码在 `com/mojang/minecraft/level/a`（`public final class`，l.r 字段）：

| 方法 | 签名 | 说明 |
|---|---|---|
| 存盘 | `public final boolean a(Level,File)` `(Lcom/mojang/minecraft/level/Level;Ljava/io/File;)Z` | new FileOutputStream→static a(Level,OutputStream) |
| 存流 | `public static void a(Level,OutputStream)` `(Llevel/Level;Ljava/io/OutputStream;)V` | 字节码：`new GZIPOutputStream→new DataOutputStream→writeInt(656127880)→writeByte(2)→new ObjectOutputStream→writeObject(Level)` |
| 读档 | `public final Level a(File)` `(Ljava/io/File;)Llevel/Level;` / `a(InputStream)` `(Ljava/io/InputStream;)Llevel/Level;` | `new GZIPInputStream→DataInputStream→readInt(magic)→readByte→readUTF×2→level.c(ObjectInputStream 子类).readObject` |
| 存服务器 | `public final boolean a(Level,String,String,String,String,int)` | POST "http://…/level/save.html" |
| 读服务器 | `public final Level a(String,String,int)` | GET "…/level/load.html?id=" |

- 魔数常量：`656127880`（0x2712_3328，int），格式版本字节 `2`。
- `com/mojang/minecraft/level/c extends java.io.ObjectInputStream`：重写 `readClassDescriptor()` 做类名重映射（兼容旧序列化 level）。
- 字符串证据：l.class 常量池 `level.dat`（存：ldc "level.dat"→FileOutputStream→level.a.a(Level,OutputStream)；读：FileInputStream→level.a.a(InputStream)）；"The level is corrupt!" 在 Level.class。
- **`.mine` 辨析（用户指正+补验）**：真 `.mine` 仅在 `e/k`（"Save level"菜单屏，javap 见「Premium only!…save your levels online」）= **0.30 在线上传形态**，非本地存档链路；本地存读仍走 l.class 的 level.dat（上条），与其余 Classic 同链路。**取舍：adapter 走 level.dat**。扫描陷阱：`.mine` 裸子串命中 `www.minecraft.net` URL 假阳性，须用 `\.mine(?!craft)`。
- 序列化字段即"键名"：Level 的 width/height/depth/blocks/name/creator/createTime/xSpawn/ySpawn/zSpawn/rotSpawn/growTrees/waterLevel/creativeMode…（transient 渲染态除外）。
