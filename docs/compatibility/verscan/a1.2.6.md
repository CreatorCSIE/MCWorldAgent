## 4. 物品/方块/材质注册表
- **ItemStack = `fp`**：`public int a,b,c,d`；NBT 字节码钉死 **a=Count、c=id、d=Damage**（同 0327/0629）；构造 `(dx)V Item/(nq)V Block/(iq;NBT)V/(III)V`。

- **Material = `hb`**：`public static final hb a..`（24 个，含下界材质）。
