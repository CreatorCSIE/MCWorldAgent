## 4. 物品/方块/材质注册表
- **ItemStack = `ev`**：`public int a,b,c,d`；NBT 字节码钉死 **a=Count、c=id、d=Damage**（同 0327）；构造 `(ly)V/(ly;I)V/(di)V/(di;I)V/(I)V/(II)V/(III)V/(hm;NBT)V`。
- **Block = `ly`**：注册表 `public static final ly[] n`；`protected ly(int, gb)`（gb=Material）；材质字段 `public gb bn`；getCollisionBox `f(cn,III)Lcf;`、getBrightness `c(nm,III)F`；静态实例含子类型（bb/my 等 = BlockDoor/ItemFood 系）。
- **Item = `di`**：注册表 `public static di[] c`（非 final）+ ~60 静态实例 + `protected static Random b`；useItem `a(ev,dm,cn,IIII)Z`。
- **Material = `gb`**：`public static final gb a..u`（21 个）。
- **TileEntity = `ic`**：子类 4：bd=MobSpawner(EntityId/Delay/Pig/smoke/flame)、fe=Chest(Items/Slot)、ke=Furnace(BurnTime/CookTime)、ob=Sign(Text1-4)；IInventory 接口 = `gh`。

## 8. 钉法可行性
主类 FQCN 可读使锚定比 0629 更容易（直接 Class.forName）；其余同 0629：字符串锚 + 注册表数组字段唯一性（`[Lly;`/`[Ldi;`）+ EntityList 注册串。字母表与 0629 完全不重叠（同字母异义，如 `a`=ItemStack 在 0629 是 Vec3 池类、`bf` 在 0629=TileEntity 在此=线程类），**指纹表必须逐版本独立钉，禁止跨版本复用字母**。
