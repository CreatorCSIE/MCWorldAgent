## 1. World/Level
- **FQCN = `net.minecraft.a.a.g`**（public final class）。⚠️ 0327 的 World 字母 `a.a.f` 在本版是**实体空间哈希**（a(Entity)V/b(Entity)V/a(FFF)→f），语义完全不同，不可按字母复用。
- 字段：`a,b,c` int=尺寸(width/depth/height)；`d` byte[]=blocks；`e` byte[]=data/add；`f,g` String；`h` long=seed；`i,j,k` spawn；`y` = `net.minecraft.a.c.e`（玩家，EntityLiving 声明）；`r` = `a.a.i` 实体空间索引；`o` Map=tileentity 表；`n` List=GameHooks 监听；`M` = `a.a.h` 光照引擎；`C` = `a.a.a.c`。
- getBlockId：`public final byte d(int,int,int)` → `(III)B`（读 d[]，越界钳制）；int 版 `a(III)I`。
- getBlockData：`public final byte e(III)B`。
- setBlock（静默核心）：`public final boolean a(IIII)Z`（写 d[]，返回 changed）。
- **setBlockWithNotify 等价 = `public final boolean b(IIII)Z`** = a(IIII)Z + `c(IIII)V`（六邻光照更新，内部调 private h(IIII)V）。
- `f(IIII)V`：写 e[] 高 4bit（blockAdd）并通知 hooks 监听。
- TileEntity 访问：`j(III)→a.a.b.a.a` get、`a(III,TileEntity)V` set、`i(III)V` remove。
