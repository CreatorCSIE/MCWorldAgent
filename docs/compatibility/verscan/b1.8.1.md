## 1.8.1 断代点（对 op 移植）
1. **饥饿新增**：FoodStats(kc) + foodLevel/saturation NBT —— 回血/死亡判定不再纯 health，getinfo/状态类 op 需带 food 字段
2. **经验新增**：Xp/XpLevel/XpTotal + EntityXPOrb(bg) —— 新 op 面，不影响旧 op
3. **GameType（创造模式）新增**：place/dig 的 reach/权限语义分叉
4. health 仍 int 20 点、ItemStack 仍 36+4/3int、世界高 128、.mcr region、TileEntity 8 类 —— **与 b1.7.3 无断代**
5. 类数 731→865、Block 子类 49→56：混淆字母名大面积重排（fd→rv、sn→kj、uu→lr、gm→sv、ow→ij、dv→ce…），**指纹表必须按版本单独钉**，描述符/结构不变
