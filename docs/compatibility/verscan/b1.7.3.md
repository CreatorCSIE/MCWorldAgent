## Entity 链
- Entity 基类 = `sn`（abstract，14 子类）：NBT 键 id/Pos/Motion/Rotation/FallDistance/Fire/Air/OnGround；`public void a(double,double,double)`=setLocation、`public void d(float,float)`=setRotation
- EntityLiving = `ls`（abstract extends sn）：**health = `public int Y`**，NBT 键 "Health"（short 读写，**20 点制**）；另有 AttackTime/HurtTime/DeathTime/Air 等键
- EntityPlayer = `gs`（abstract extends ls）：inventory `public ix c`；容器 `public dw d/e`（inventorySlots/openContainer）；NBT：Inventory/Sleeping/SleepTimer/SpawnX/Y/Z/Dimension（**床已存在**）
- EntityClientPlayerMP = `dc`（extends gs，Minecraft.h）；EntityPlayerMP = `ii`（extends ls, ctor (fd)）
- EntityItem = `yl`（extends sn implements lw，持 `iz[]`）
- EntityList = `jc`（含 "Painting"；**无 "XPOrb"** → 经验球不存在）

## 背包/物品
- InventoryPlayer = `ix`：ctor `ix(gs)`；`public iz[] a` = **36 槽**（bipush 36）、`public iz[] b` = **4 槽**（iconst_4）→ 27+9+4 ✓；`public int c`=currentItem
- ItemStack = `iz`：3 个 int 字段 `a/b/c`（stackSize/damage/count 语义同 0327，**无 NBT tag 字段**）；ctor `(uu)`(Block)/(gm)(Item)/(III)/(nu)(NBT)；`public gm a()`=getItem；`public iz a(int)`=decrement；`a(gs,fd,IIII)Z`=onItemUseFirst
- Block = `uu`（484 行）：注册表 `public static final uu[] m`（byId），85 个静态实例，49 子类，ctor `uu(int, ln)`（ln=Material），StepSound 值类 `ct`(String,F,F)×9
- Item = `gm`（339 行）：注册表 `public static gm[] c`，104 静态实例，27 子类；`float a(iz,uu)`=getStrVsBlock

## TileEntity = `ow`
- `public fd d`（world）+ `public int e/f/g`（x,y,z）；`a(nu)/b(nu)`=read/writeFromNBT（nu=NBTTagCompound）；保留名 `n_()`(update)/`y_()`；静态 `a(Class,String)` 注册 + `c(nu)` 工厂
